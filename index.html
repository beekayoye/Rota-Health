Rota Health Design Tokens

Strict Two-Tier Color Architecture separating foundational primitives from semantic UI color roles. Complete with DM Sans typography, 4/8-point spacing scales, and multi-layer elevation.

🛑 FOUNDATION TIER (DO NOT USE ON UI)

Primitive Colors (--primitive-color-*)

Raw color values and 0–100 tonal palette stops. These are foundational building blocks meant exclusively to feed semantic roles. Never hardcode primitive colors in component stylesheets, as it breaks dark mode, theming, and accessibility contrast.

✅ APPLICATION TIER (USE ON UI)

Color Roles (--color-role-* / --color-*)

Contextual, semantic tokens representing functional intent (e.g. primary, on-primary, surface, error). These are the tokens developers must apply directly to UI components. Each role automatically maps to a primitive foundation.
